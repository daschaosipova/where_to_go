# Куда пойти

Интерактивная карта интересных мест Москвы. На карте отмечены локации,
а по клику на метку открывается боковая панель с фотографиями и описанием.
Данные (места и фотографии) хранятся в базе данных и редактируются через
админку Django.

## Возможности

- Интерактивная карта Москвы с метками мест; по клику открывается боковая
  панель с фотографиями и описанием.
- Админка для контент-менеджера: поиск по названию, загрузка фото прямо на
  странице места, превью картинок и сортировка галереи перетаскиванием.
- Длинное описание редактируется визуальным редактором (TinyMCE).
- Наполнение базы из JSON-файлов: команда `load_places` загружает все локации
  разом, `load_place` — одну по ссылке.

## Демо

Сайт разворачивается локально. Ссылки на опубликованную версию появятся
здесь после деплоя.

## Источник данных

Проект сделан на основе учебного задания курса
[«Django» от Devman](https://dvmn.org/). Тестовые данные взяты из
репозитория [devmanorg/where-to-go-places](https://github.com/devmanorg/where-to-go-places).
Это **учебный проект**, а не коммерческий сервис.

## Формат JSON-файла с локацией

Каждая локация описывается одним JSON-файлом. Пример сокращён:
в полном файле обычно несколько фотографий и более длинное описание.

```json
{
    "title": "Экскурсионная компания «Легенды Москвы»",
    "imgs": [
        "https://raw.githubusercontent.com/devmanorg/where-to-go-places/master/media/4f793576c79c1cbe68b73800ae06f06f.jpg",
        "https://raw.githubusercontent.com/devmanorg/where-to-go-places/master/media/1e27f507cb72e76b604adbe5e7b5f315.jpg"
    ],
    "description_short": "Неважно, живёте ли вы в Москве всю жизнь или впервые оказались в столице, составить ёмкий маршрут по городу — творческая и непростая задача.",
    "description_long": "<p>Экскурсия от компании «Легенды Москвы» — простой и приятный способ познакомиться с городом.</p>",
    "coordinates": {
        "lng": "37.64912239999976",
        "lat": "55.77754550000014"
    }
}
```

## Быстрый старт

1. Клонируйте репозиторий и перейдите в его папку:

   ```bash
   git clone https://github.com/daschaosipova/where_to_go.git
   cd where_to_go
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` на основе `.env.example` и задайте свой `SECRET_KEY`:

   ```bash
   cp .env.example .env
   ```

5. Примените миграции:

   ```bash
   python manage.py migrate
   ```

6. Создайте суперпользователя для входа в админку:

   ```bash
   python manage.py createsuperuser
   ```

7. Наполните базу местами из репозитория
   [devmanorg/where-to-go-places](https://github.com/devmanorg/where-to-go-places).
   Можно загрузить все локации сразу:

   ```bash
   python manage.py load_places
   ```

   Или по одной:

   ```bash
   python manage.py load_place https://raw.githubusercontent.com/devmanorg/where-to-go-places/master/places/Экскурсионная%20компания%20«Легенды%20Москвы».json
   ```

8. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

   Сайт откроется на [http://127.0.0.1:8000/](http://127.0.0.1:8000/),
   админка — на [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/).

## Как редактировать контент

1. Войдите в админку по адресу `/admin/`.
2. Откройте раздел «Интересные места».
3. Найдите место по названию через поиск или добавьте новое.
4. На странице места отредактируйте тексты и загрузите фотографии прямо
   в форме места. Порядок фотографий меняется перетаскиванием.

## Переменные окружения

| Переменная      | Описание                                       | Пример                    |
|-----------------|------------------------------------------------|---------------------------|
| `SECRET_KEY`    | Секретный ключ Django. **Обязателен.**         | `change-me`               |
| `DEBUG`         | Режим отладки (`True` только для разработки).  | `True`                    |
| `ALLOWED_HOSTS` | Список доменов через запятую.                  | `localhost,127.0.0.1`     |
| `DATABASE_URL`  | URL базы данных. Необязательна: по умолчанию SQLite. | `postgres://user:pass@host/db` |
