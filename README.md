# Куда пойти

Интерактивная карта интересных мест Москвы. На карте отмечены локации,
а по клику на метку открывается боковая панель с фотографиями и описанием.
Данные (места и фотографии) хранятся в базе данных и редактируются через
админку Django.

## Демо

- **Сайт:** https://<логин>.pythonanywhere.com/
- **Админка:** https://<логин>.pythonanywhere.com/admin/

## Источник данных

Проект сделан на основе учебного задания курса
[«Django» от Devman](https://dvmn.org/). Тестовые данные взяты из
репозитория [devmanorg/where-to-go-places](https://github.com/devmanorg/where-to-go-places).
Это **учебный проект**, а не коммерческий сервис.

## Быстрый старт

1. Клонируйте репозиторий и перейдите в его папку:

   ```bash
   git clone https://github.com/daschaosipova/where_to_go.git
   cd where_to_go
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` на основе `.env.example` и задайте свой `SECRET_KEY`:

   ```bash
   cp .env.example .env
   ```

5. Примените миграции:

   ```bash
   python manage.py migrate
   ```

6. Создайте суперпользователя для входа в админку:

   ```bash
   python manage.py createsuperuser
   ```

7. Наполните базу тестовыми местами (можно несколько раз, по одному месту):

   ```bash
   python manage.py load_place https://raw.githubusercontent.com/devmanorg/where-to-go-places/master/places/Экскурсионная%20компания%20«Легенды%20Москвы».json
   ```

8. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

   Сайт откроется на [http://127.0.0.1:8000/](http://127.0.0.1:8000/),
   админка — на [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/).

## Как редактировать контент

1. Войдите в админку по адресу `/admin/`.
2. Откройте раздел «Интересные места».
3. Найдите место по названию через поиск или добавьте новое.
4. На странице места отредактируйте тексты и загрузите фотографии прямо
   в форме места. Порядок фотографий меняется перетаскиванием.

## Переменные окружения

| Переменная      | Описание                                       | Пример                    |
|-----------------|------------------------------------------------|---------------------------|
| `SECRET_KEY`    | Секретный ключ Django. **Обязателен.**         | `change-me`               |
| `DEBUG`         | Режим отладки (`True` только для разработки).  | `True`                    |
| `ALLOWED_HOSTS` | Список доменов через запятую.                  | `localhost,127.0.0.1`     |
